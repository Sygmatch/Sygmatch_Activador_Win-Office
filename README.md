Sygmatch Activator
Gestor, Activador y Diagnóstico Profesional para Windows y Office

Sygmatch Activator es una herramienta moderna de escritorio desarrollada en PowerShell con una interfaz gráfica optimizada en Modo Oscuro. Ofrece una solución limpia, automatizada y segura para gestionar, activar y diagnosticar licencias de Microsoft Windows y Microsoft Office sin complicaciones ni menús molestos.

Características Principales

* Interfaz Gráfica Moderna: Desarrollada con Windows Forms en un diseño oscuro elegante, con consola interna integrada en tiempo real y traducción automática de estados técnicos al español.
* Ejecución Segura: Comprobación automática de privilegios de Administrador y creación inteligente de un Punto de Restauración del Sistema antes de realizar cualquier cambio crítico.
* Activación Desatendida: Los procesos se ejecutan de manera fluida en segundo plano sin congelar la interfaz ni mostrar pantallas de comandos intermedias.

Funciones del Panel de Control

Activar Windows (HWID - Permanente)
Aplica una licencia digital permanente basada en el hardware del equipo de forma completamente desatendida y oficial.

Activar Office (Ohook - Permanente)
Implementa el emulador Ohook para otorgar una activación perpetua y estable a Microsoft Office (compatible con Office 2016, 2019, 2021 y 365) sin alterar las licencias nativas del sistema operativo.

Activar Windows / Office (KMS Online)
Permite seleccionar de manera independiente qué producto activar mediante servidores KMS públicos por un período de 180 días, detectando automáticamente la edición del sistema y configurando las claves de volumen correspondientes.

Cambiar Edición de Windows
Permite cambiar la edición actual del sistema operativo de forma segura, filtrando únicamente las ediciones compatibles con tu arquitectura para proteger la estabilidad y el registro de Windows.

Limpieza de Licencias
Herramienta de purga independiente que permite eliminar por completo claves de producto instaladas, servidores KMS configurados y rastros de licencias anteriores tanto para Windows como para Office de forma separada.

Comprobación de Licencias
Realiza un escaneo profundo y simultáneo del estado de licencias de Windows y Office, detectando el tipo exacto de activación utilizada y mostrando los resultados con códigos de color intuitivos.

Requisitos del Sistema

* Sistema Operativo: Windows 10 o Windows 11 (Compatible con ediciones Home, Pro, Enterprise y LTSC / IoT).
* Permisos: Privilegios de Administrador (el script se auto-eleva de manera automática si es necesario).
* Dependencias: PowerShell 5.1 o superior (nativo en Windows).

Uso Rápido

1. Descarga o clona este repositorio.
2. Haz clic derecho sobre el archivo ejecutable o script y selecciona Ejecutar como administrador.
3. Utiliza el panel izquierdo para seleccionar la acción deseada y visualiza los resultados en tiempo real en la consola integrada.
