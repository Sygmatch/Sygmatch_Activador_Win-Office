Sygmatch - Activador de Windows y Office en PowerShell

Bienvenido a la version moderna de Sygmatch desarrollada integramente en PowerShell, diseñada para facilitar la gestion, activacion y mantenimiento de licencias de los sistemas operativos Windows y la suite de Microsoft Office mediante un entorno robusto y automatizado.

Caracteristicas principales:

Creacion automatica opcional de un punto de restauracion del sistema antes de realizar cualquier cambio para garantizar la seguridad del equipo.
Elevacion automatica de privilegios que solicita permisos de Administrador de manera transparente si el script no se ejecuta con ellos.
Activacion permanente de Windows mediante el metodo HWID vinculado al hardware del equipo.
Activacion permanente de Microsoft Office utilizando el metodo local Ohook.
Metodo alternativo de activacion online mediante servidores KMS con una vigencia de 180 dias tanto para Windows como para Office.
Herramienta integrada para cambiar de edicion en Windows de forma rapida y sencilla (por ejemplo, pasar de versiones Home a Pro o Enterprise).
Opcion avanzada de limpieza para purgar claves de producto, servidores KMS y restablecer por completo las licencias de Windows, de Office o de ambos sistemas a la vez.
Comprobacion de estado detallada que verifica de manera simultanea y en una sola interfaz la licencia actual de Windows y de Office instalado.

Instrucciones de uso:

1. Descarga o clona este repositorio en tu ordenador.
2. Haz clic derecho sobre el archivo .bat o directamente sobre el script principal en PowerShell y asegurate de ejecutarlo. El sistema se encargara de solicitar los permisos de Administrador necesarios de forma automatica.
3. Interactua con el menu visual en pantalla introduciendo el numero de la opcion que prefieras y presiona Enter para ejecutarla.

Aviso importante: Este desarrollo tiene un enfoque estrictamente de gestion tecnica y educativa. Utiliza las herramientas de activacion bajo tu propia responsabilidad y asegurate de cumplir siempre con las normativas y politicas de software vigentes en tu localidad.
